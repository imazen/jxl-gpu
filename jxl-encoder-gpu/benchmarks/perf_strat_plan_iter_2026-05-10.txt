Notes
-----
- 50% of per-iter wall-clock is mixed_strategy_encode_recon (the GPU
  encode + scatter chain). 36% is download_crop (PCIe pull of the
  reconstructed XYB plane back to host so the host-side metric +
  refinement can read it).
- For the butteraugli refinement loop, download_crop is unnecessary
  if the next iter's metric / aq-field update can run on GPU. That
  is the next obvious optimization (~5.9 ms/iter saving, ~36% of
  per-iter wall-clock).
- This synthetic gradient is unusually DCT64x64-heavy (57%) — real
  photos are DCT8-heavy and exercise different code paths. Re-run on
  a CLIC photo to capture realistic mix.
